Реалізуйте систему управління бібліотекою, яка дозволяє додавати книги, шукати їх за різними критеріями, а 
також вести облік відомостей про книги (наприклад, назва, автор, рік видання, жанр, кількість копій). Також 
потрібно реалізувати можливість оренди книг, з можливістю перевірки доступності.

Клас Book
Атрибути:
title: Назва книги.
author: Автор книги.
year: Рік видання.
genre: Жанр книги.
copies: Кількість копій книги в бібліотеці.
Методи:
is_available(): Повертає True, якщо хоча б одна копі
rent(): Зменшує кількість доступних копій на 1 при оренді книги.
return_book(): Збільшує кількість доступних копій на 1 при поверненні книги.
Клас Library
Атрибути:
books: Список книг у бібліотеці (список об'єктів класу Book).
Методи:
add_book(book): Додає книгу до бібліотеки.
search_by_author(author): Повертає список книг, автори яких відповідають запиту.
search_by_genre(genre): Повертає список книг за жанром.
search_by_title(title): Повертає список книг за назвою.
rent_book(title): Орендує кни
